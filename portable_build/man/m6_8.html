6.8. Генерація звіту форми 46.

Для генерації звіту за формою 46 необхідні файли бази даних для складів підрозділів. Причина цього полягає в тому, що окрема база даних не має інформації про рух товару того підрозділу, на який була видача товару. Для конкретної бази рух товару закінчується з накладною на видаток. Форма 46 вимагає знання руху у підрозділах. Тому для коректної побудови звіту необхідно створити та вести бази даних підрозділів централізовано, а 46 додаток повинен формуватись із основного складу, наприклад складу бригади, відносно до підрозділів на які видається товар. Для формування звіту програма надає широкий арсенал автоматизації: 1)видаткові накладні на підрозділ з БД бригади можуть бути експортовані як прибуткові накладні для складу підрозділу. 2)видаткові накладні підрозділа (витрата) можуть бути імпортовані з накладних та карт-звітів. 3)витрата підрозділу по днях може бути сформована по меню розкладці та кількості людей на котловому забезпеченні на кожен день. Зазначена автоматизація дозволяє вести бази даних для підрозділів із мінімальними витратами часу. Форму для генерації звіту показано на мал. 6.12.

Мал. 6.12. Форма для створення звіту за формою 46

Таблиця у зазначеній формі призначена для набору файлів баз даних для всіх підрозділів, які мають бути у звіті. Ця таблиця має два поля - одне для вставки повного шляху до конкретної бази даних, друге це список, що випадає, з якого слід вибрати підрозділ, що відповідає вставленій базі даних. Така система вибору необхідна тому що сам собою файл бази даних немає точної інформації для якого підрозділу він ведеться. Після введення всіх необхідних пар «файл бази-ім'я підрозділу» та вказівки періоду часу можна згенерувати звіт за формою 46, де кожна сторінка буде звітом про рух для однієї позиції з каталогу. У звіті будуть присутні лише ті позиції, якими був рух. Після генераціі звіту ви можете швидко перейти до сторінки с бажаною позицією використовуючи випадаючий список товарів.

Зверніть увагу на дуже важливу річ. Оприбуткування на підрозділ, с точки зору 46 додатку, може виконуватись двома варіантами. Перший це експорт видаткової накладної з основної БД (наприклад бригади) до БД підрозділа. Другий варіант це пряме оприбуткування в БД підрозділа, не задіючи експорт. В другому випадку таке оприбуткуваня означає що позиціі були отримани поза складом бригади, а це означає що в 46 додатку це буде відображатись по іншому. Різниця полягає в тому, що при другому варіанті (пряме надходження на склад підрозділа), графа "на складі" для бригади не буде змінюватись, але графа "по документам" відобразить це надходження. Для першого варіанту (надходження через експорт) сітуация буде обратною: значення поля "на складі" буде змінено, а поле "по документам" ні. Коректне використання експорту та прямого оприбуткування важливо для формування 46 додатку. Якщо товар на підрозділ прибув з основного складу, завжди використовуйте експорт для оприбуткування в БД підрозділа, це встановлює внутрішній зв'язок даних та дозволяє коректно формувати 46 додаток. Якщо товар на підрозділ прибув не з основного складу, завжди використовуйте ручне введення накладної надходження, без експорту, навіть якщо це надходження було з якогось другого вашого складу (не основного).
