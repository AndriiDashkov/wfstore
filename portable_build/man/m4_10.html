4.10.Імпорт видаткових накладних з XML.

Імпорт видаткових накладних з XML файлу можна здійснити за допомогою меню імпорта - дв. мал. 4.14. В формі для імпорта вкажить шлях до XML файлу та контрагента. Імпорт можливий тількі якщо файл XML має відповідний формат, а саме формат який генерується програмою PS.

Якщо ви активуєте флаг "створювати нових отримувачів із XML", то додаток буде створювати нових контрагентів з XML файлу який імпортується. Якщо якийсь документ в XML не має вказівок на контрагента, то буде використаний контрагент якого вибрано із списку "Отримувач/підрозділ". У випадку коли флаг "створювати нових отримувачів із XML" не активований, для всіх імпортованих накладних буде використано контрагента вибраного у списку. Контрагентів за потреби можно змінити в режимі редагування накладних.

Протягом імпорту може виникати нестача деяких товарів. У цьому випадку в сгенерованих накладних поле Інфо буде мати відповідну інформацію про цю нестачу.
