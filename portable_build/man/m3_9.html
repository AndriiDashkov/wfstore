3.9.Імпорт накладних надходження з XML.

Для імпорту накладних надходження з XML використовуйте контекстне меню яке показано на мал. 3.17. Імпорт можливий тільки для XML файлів формату, які генеруются програмой PS. Якщо файл буде в іншому форматі, імпорт буде неможливий. При імпорті генеруются накладні для контрагента, якого ви вказуєте із випадаючого списка. Якщо в деяких накладних вам буде потрібно іншого контрагента, вам потрібно змінити його через режим редагування накладних. Тестовий договір вставляється автоматично. Якщо вам треба змінити договора для накладних, ви можете використати відповідну групову операцію для зміни договорів.
